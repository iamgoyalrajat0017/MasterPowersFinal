## ✨ About

**MasterPowers** brings the elemental combat of *Avatar: The Last Airbender* and *The Legend of Korra* into Minecraft. Choose an element, master its abilities, and battle other players using dynamic, skill-based combat — all built for **Night SMP**.

## 🌟 Key Features

- 🔥 **Five core elements** — Air, Water, Earth, Fire, and Chi — each with a distinct playstyle
- 🌊 **Subelements** — Bloodbending & Icebending for Water, Metal & Lavabending for Earth, and more
- ⚡ **Combo system** — chain abilities together to unleash powerful combo moves
- 🛡️ **Deep permission support** — fine-tune exactly who can bend what
- ⚙️ **Fully configurable** — tune every ability, cooldown, and mechanic to fit the server
- 🧩 **Modular abilities** — 40+ abilities included, each toggleable independently
- 🎨 **Element-based chat formatting** — your bending shows in how you talk

## 🥋 The Elements

| Element | Playstyle |
|---|---|
| **Airbending** | Mobility & defense — scooters, shields, tornadoes, and suffocation. Fast, evasive, low raw damage. |
| **Waterbending** | Control near water — freezing, torrents, waves. Balanced offense and defense. |
| **Earthbending** | Terrain manipulation — armor, walls, launches, and earth blasts. Sturdy and versatile. |
| **Firebending** | Aggressive, high-damage playstyle — fire blasts, walls of flame, and lightning. Low mobility. |
| **Chiblocking** | Bare-handed combat — blocks enemy bending, hits hard, weak on defense. |

## 📥 Installation

1. Drop the built `MasterPowers.jar` into your server's `plugins/` folder
2. Restart the server
3. Run `/mp help` in-game or console for a full command overview

## 🎮 Commands

Run `/mp help` for a full list — every command is permission-gated (see `plugin.yml`). Core aliases: `/mp`, `/bending`, `/b`, `/bend`.

## 🛠️ Building From Source

```bash
git clone https://github.com/iamgoyalrajat0017/MasterPowersFinal.git
cd MasterPowersFinal
mvn clean package
```

Builds also run automatically via GitHub Actions on every push to `main`.
